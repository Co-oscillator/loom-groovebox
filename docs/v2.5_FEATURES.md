# Loom Groovebox v2.5 Features to Implement

## Play Screen Pad Bend & Modulation
*   **Tap-and-Drag functionally on Play screen pads:**
    *   **X-Axis (Left/Right Slide):** Controls pitch bend up and down.
    *   **Y-Axis (Up/Down Slide):** Controls a routable modulation parameter.
*   **New MIDI Learn Button ("Pad Bnd Lrn"):**
    *   *Placement:* Added 150dp above the transpose controls on the Play screen.
    *   *Interaction:* Tapping this button activates MIDI learn highlighting mode.
    *   *Routing:* While highlighting is active, the user can select any parameter on the screen. The Y-axis (up/down slide) will then control that parameter.
*   **Default Y-axis parameter:**
    *   By default, the up/down slide should be mapped to the filter cutoff in the currently selected engine.
    *   If the selected engine lacks a filter cutoff parameter, it should default to blank/unassigned.
